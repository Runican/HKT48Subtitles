# HKT48Subtitles

Public assets for Japanese→English HKT48 subtitle work: a shared glossary and cast index, stage templates, curated source notes, and reusable workflow guides (ASS pipeline + talk-segment finder).

Published stage ASS files live under `shows/stages/[year]/`. Other completed deliverables will use `subs/[type]/[year]/` (year optional when a type has no yearly split). Show audio and other media are not committed to git.
