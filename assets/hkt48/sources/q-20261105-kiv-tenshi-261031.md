## Lore questions on the draft (2026-11-05)
LOCK = official or reference source confirms; PROV = best reading, ear decides; UNKNOWN = no source.

1. **夢のdead body → "Yume no Dead Body": LOCK.** It is M05 of the stage (official 表記 夢のdead body), the first unit slot, a solo song. Source: https://ja.wikipedia.org/wiki/チームN_3rd_Stage「ここにだって天使はいる」 ; same form in the fan setlists for 250405 and 250427. It is a real song title, so the "unresolved" remark in the 250413 note does not apply to Tenshi.
2. **ジッパー → "Zipper": LOCK.** It is M09, the fifth unit song (a trio). ジンパー is an ASR slip. Same source. The 250405 and 250427 fan setlists and 261028/261029 fan posts also use ジッパー.
3. **Halloween call in the encore MC: PROV.** No glossary or Tenshi note has a Hallowein / ハロウェイン / Hello Music lock. It was a one-off Halloween-day call, not durable canon. Follow the host's word and render it "Halloween!"; do not subtitle a crowd flub as "Hello! Music!" unless the ear is clear. Not added to the glossary.
4. **Eura interactive catch: LOCK (glossary `eura-yuka`).** The locked pattern is いつも愉快な→ゆうか / これは→床 / わたしは→優香. Keeping only the prompts ("This is?" / "I am?") is acceptable if the crowd replies can't be heard. If they can be heard, add Crowd "Floor!" / "Yuka!" (the 床/優香 pun).
5. **Eguchi and Akiyoshi catches: stable.** Eguchi's look-for / ここだよー catch matches `eguchi-lookfor-catch` (LOCKED). For a name line cut off in ASR, "Koko-chan, Eguchi Kokoha" follows from the cast list and the catch: PROV, ear. Akiyoshi's 「博多に咲く優しい花になりたい」 matches `yukatan-yasashii-hana-catch` (LOCKED). ASR 九州花 is the 優花 misread, so Akiyoshi Yuka: LOCK. No catch drift this show.
